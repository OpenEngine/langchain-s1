# TypeScript: API reference

The reference below is **not written by hand**: [TypeDoc](https://typedoc.org/)
generates it from `typescript/src` on every build, so it always matches the published
`langchain-s1` npm package. As the TypeScript port grows, this reference grows with it.

!!! info
    **Open the generated reference** — it renders as a standalone page with its own
    navigation, search, and "edit on GitHub" links:
    <a href="../../typescript-api/index.html">typescript-api/index.html</a>

The package currently exports:

- `VERSION` — the package version.

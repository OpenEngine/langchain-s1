# TypeScript: API reference

The package is currently a **stub**: it exports only `VERSION`, and the
`S1Client`/`S1Decision`/`s1Gate` port is in progress (the [guide](guide.md) describes
the planned surface). The reference is generated from `typescript/src` with
[TypeDoc](https://typedoc.org/) on every build, so it grows as the port lands —
nothing is maintained by hand.
